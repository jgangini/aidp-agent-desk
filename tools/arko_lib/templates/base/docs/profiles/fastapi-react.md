# FastAPI + optional React profile

Source: ADR 0001; verified with the committed lockfiles. Status: implemented.

`backend/app/features/NAME/api.py` adapts HTTP; `service.py` owns behavior;
`schemas.py` is the public data contract. Services/schemas cannot import HTTP
frameworks or route modules. Schemas cannot import services. `app/core` cannot
import features. Cross-feature Python imports may reference only `schemas` from
declared dependencies. Relative imports are resolved by AST.

`frontend/src/features/NAME` contains `api.ts`, component and test. Shared code
does not import features. Cross-feature imports use declared dependencies and
their `api.ts`. TypeScript compiler AST checks import/export/dynamic import
specifiers; nonliteral imports are rejected. No custom path aliases in v0.1.
The UI composition root has no mandatory product screen or styling.

OpenAPI comes from the running Python definitions. `contracts/openapi.json` is
the current export; `baseline.json` is the explicitly accepted contract. TS types
are generated by openapi-typescript; openapi-fetch consumes them. Compatibility
checking is conservative, not full OpenAPI semantics: existing structural changes
require review; new paths, schemas and optional properties are accepted. False
positives on compatible constraint widening are intentional. Extend with a proven
semantic diff tool when richer compatibility policies become necessary.

Quick start: `python tools/arko.py setup --root .`, then `check` and `dev`.
uv sync uses uv.lock; npm ci uses package-lock.json. Python 3.12+, Node 22.12+.
Vite proxies `/api` to loopback backend. Production Docker serves built assets
from FastAPI. Client-side history routing/fallback is not installed.

The sample bearer credential maps to one local identity and fails closed when
unconfigured. Set ARKO_API_TOKEN in the shell; never use VITE_* for secrets.
For a multi-user application replace `current_user` with verified OIDC/session
identity and review CSRF if using cookies. Add persistence, edge TLS, request
limits and operational controls for production. The sample store is ephemeral,
single-process and unsuitable for durable or multi-worker production use.
