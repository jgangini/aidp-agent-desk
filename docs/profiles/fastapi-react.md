# FastAPI + optional React profile

Source: ADR 0001; verified with the committed lockfiles. Status: implemented.

`backend/app/features/NAME/api.py` adapts HTTP; `service.py` owns behavior;
`schemas.py` is the public data contract. Services/schemas cannot import HTTP
frameworks or route modules. Schemas cannot import services. `app/core` cannot
import features. Cross-feature Python imports may reference only `schemas` from
declared dependencies. Relative imports are resolved by AST.

`frontend/src/features/NAME` contains `api.ts`, component and test. Shared code
does not import features. Cross-feature imports use declared dependencies and
their `api.ts`. TypeScript compiler AST checks import/export/dynamic import
specifiers; nonliteral imports are rejected. No custom path aliases in v0.1.
The UI composition root has no mandatory product screen or styling.

OpenAPI comes from the running Python definitions. `contracts/openapi.json` is
the current export; `baseline.json` is the explicitly accepted contract. TS types
are generated by openapi-typescript; the scaffold client uses openapi-fetch. The
Desk transport validates its streamed public packets separately. Compatibility
checking is conservative, not full OpenAPI semantics: existing structural changes
require review; new paths, schemas and optional properties are accepted. False
positives on compatible constraint widening are intentional. Extend with a proven
semantic diff tool when richer compatibility policies become necessary.

Quick start: `python tools/arko.py setup --root .`, then `check` and `dev`.
uv sync uses uv.lock; npm ci uses package-lock.json. Python 3.12+, Node 22.12+.
Vite proxies `/api` to loopback backend. Production Docker serves built assets
from FastAPI. Client-side history routing/fallback is not installed.

The bearer helper in core/auth.py is retained for generated Arko features and
fails closed without ARKO_API_TOKEN; Desk does not use it for its local admin
routes. Desk uses exact local Origin plus a custom header, server-side OCI
credentials and a private data directory. This is a local single-user boundary,
not multi-user authentication. Hosted mode installs the separate Oracle identity/session and authorization boundary in app/core/access.py; see SECURITY.md and docs/deployment.md.

Desk declares backend 8317 and frontend 5178 in .arko/project.json; its Vite proxy
targets 8317. The generic scaffold retains defaults 8000/5173. Windows can use
scripts/dev.ps1 to check that Desk ports are free first.

Optional DOM regressions use scripts/arch-postflight.ps1 with
AGENT_DESK_PLAYWRIGHT_MODULE pointing to an already installed Playwright module.
Run a local Desk server and set AGENT_DESK_CONTENT_BROWSER_URL for the isolated
content-items suite; this route intercepts cloud APIs and preserves user data.
The general browser-check.cjs route uses http://127.0.0.1:8317 and synthetic QA
credentials generated under .cache. It changes configuration during its scenarios
and requires a dedicated test instance without user data. Its entry point runs
the welcome, demonstration, configuration, publication, streaming and history
scenarios in order; each scenario retains its explicit assertions. No screenshots,
recordings or traces are taken. No dependency or browser download is part of
these checks.

La suite integrada de tareas reutiliza `scripts/browser-check.cjs` con
`AGENT_DESK_SCHEDULED_BROWSER_URL=http://127.0.0.1:8320` y el módulo Playwright
instalado indicado en `AGENT_DESK_PLAYWRIGHT_MODULE`. Puede fijarse
`AGENT_DESK_BROWSER_EXECUTABLE` a un Chromium ya instalado; no descarga motores.
Iniciar antes una instancia dedicada con
`AGENT_DESK_DATA_DIR=<repo>/.cache/report-qa-private` y
`uv run python -m uvicorn scripts.scheduled_browser_fixture:app --port 8320`.
Esta fixture falla fuera de `.cache` o en modo Oracle. La suite comprueba prueba
inicial, recarga sin invocar, descarga, ajuste sin captura, ejecución manual,
pausa, borrado de su tarea sintética y diálogo móvil. No usa cuentas cloud,
capturas, vídeos ni trazas. El wrapper postflight ejecuta esta ruta cuando se
configura su URL; no ejecutar la suite contra datos del usuario.

## Local architecture map

Graphify 0.9.93 (`graphifyy`) produces a local AST map with
`./scripts/graphify.ps1`. The same command initializes an absent map or updates
an existing one, then writes `graphify-out/GRAPH_REPORT.md`, `wiki/index.md` and
`graph.html`. `-NoHtml` skips the interactive export. No model backend, API key,
Git hook or global index is used. The postflight wrapper refreshes an existing
map; Graphify is optional for a fresh clone until explicitly initialized.

`.graphifyignore` complements Git exclusions: credentials, private execution
evidence, Markdown documents, caches, dependency trees, generated API types, vendored UI assets and
scaffold templates are outside the map. `graphify-out/` is local generated
output, excluded from Git, Docker and Semble. Maintained application code and
tests remain in scope. Imported external symbols can still appear as endpoints;
their presence does not mean dependency source was indexed.

Install the pinned tool with `uv tool install "graphifyy[terraform,sql]==0.9.93"`.
These extras include Terraform/HCL and SQL parsers alongside Python and
TypeScript. Native Terraform validation remains in postflight. Some test files
without exported symbols have no AST nodes. Treat
inferred graph edges as navigation hints and verify them against code.

Sentrux uses the original `.sentrux/baseline.json`, independently of Graphify.
`sentrux gate .` failures propagate through preflight and postflight. There is
no `.sentrux/rules.toml`; no language threshold or baseline is relaxed by the
Graphify setup. Functional checks do not establish structural gate acceptance.
